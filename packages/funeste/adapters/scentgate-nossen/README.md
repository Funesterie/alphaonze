# @funeste/scentgate-nossen

Private NOSSEN adapter for $publicPkg@2.0.0.

This restricted package exists to give the Funeste/NOSSEN workspace a private install target while the reusable implementation remains public under $publicPkg.

## Install

`ash
npm install @funeste/scentgate-nossen
`

## Security

This package does not contain secrets, tokens, private endpoints, or operator credentials. Runtime secrets must come from environment variables, a local vault, or a provider dashboard.
