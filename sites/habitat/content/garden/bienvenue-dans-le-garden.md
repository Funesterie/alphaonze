# Bienvenue dans le Garden

Le Garden, c'est l'endroit où **tout peut pousser**.

Comme un vrai jardin, les notes ici sont :

- **En évolution constante** : Une idée aujourd'hui peut devenir un projet demain
- **Non structurées** : Pas de pression, pas de format imposé
- **Libres** : À modifier, supprimer, ou laisser en jachère

## Pourquoi un Garden ?

Parce que les meilleures idées naissent souvent de graines plantées sans attente.

> *"Un jardin, c'est le seul endroit où on peut semer un rêve et le voir pousser."*

## Comment l'utiliser

1. **Plante** une nouvelle note (créer un fichier `.md`)
2. **Arrose** la régulièrement (modifie-la)
3. **Récolte** quand c'est prêt (déplace-la vers Blog ou Projects)

LightKamel veille sur chaque plante. 🌱
