# Funesterie

**Funesterie** est une plateforme qui permet de **créer, explorer et interagir** avec des agents IA de manière unique.

## Features

### 🎯 MCP Server
Un serveur MCP (Model Context Protocol) qui connecte différents modèles et outils.

### 🤖 Agents
Des assistants IA spécialisés pour différentes tâches.

### 🌐 Bridge
Un système de connexion entre les modèles et les applications.

## Technologie

- **TypeScript** pour le backend
- **Next.js** pour les interfaces
- **Cloudflare Workers** pour le déploiement
- **Neo4j** pour la gestion des connaissances
