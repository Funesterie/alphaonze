# A11 / K44 Public MCP Endpoints - 2026-05-13

## Canonical endpoints

- A11: `https://a11.funesterie.pro/mcp`
- K44: `https://k44.funesterie.me/mcp`
- K44 legacy alias: `https://kaen44.funesterie.me/mcp`

Also exposed for discovery:

- `/.well-known/mcp`
- `/.well-known/mcp.json`
- `/api/mcp/status`

## Notes on requested aliases

- `a11.funesteri.pro` is a typo / unrouted hostname. Use `a11.funesterie.pro`.
- `k44.me` is not routed to Funesterie DNS. Use `k44.funesterie.me`.

## Public tool surface

The public MCP route intentionally exposes only safe tools:

- `a11_health`
- `a11_llm_stats`
- `a11_chat`
- `a11_mcp_public_status`

No shell, filesystem, secrets, tokens, deployment, or admin routes are exposed through the public MCP endpoint. Chat goes through the same HTTP guardrails as `/api/chat`.

## Kiro entries

The Kiro MCP config now includes:

- `a11mcp-public-a11` -> `https://a11.funesterie.pro/mcp`
- `a11mcp-public-k44` -> `https://k44.funesterie.me/mcp`

Only safe status tools are auto-approved.

```bash
curl -fsS https://a11.funesterie.pro/mcp
curl -fsS https://k44.funesterie.me/mcp
curl -fsS https://kaen44.funesterie.me/.well-known/mcp
```

