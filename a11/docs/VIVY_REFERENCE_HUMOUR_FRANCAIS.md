## Ce que le morceau enseigne

Le texte prend la forme d’une chanson d’amour naïve. Le chanteur prépare régulièrement une phrase dont la fin semble évidente, marque une pause, puis choisit un complément innocent. L’auditeur a déjà fabriqué une autre fin dans sa tête : le rire vient de cet écart.

La force du procédé repose sur cinq éléments :

1. **Sincérité apparente**  
   Le chanteur ne joue pas la malice. Il interprète la chanson comme une déclaration réellement tendre.

2. **Syntaxe orientée**  
   La phrase est construite pour appeler une conclusion précise avant même qu’elle arrive.

3. **Césure active**  
   La pause laisse au public le temps de compléter mentalement la phrase.

4. **Résolution innocente**  
   Le mot réellement chanté reste banal, grammatical et cohérent avec la chanson d’amour.

5. **Accumulation maîtrisée**  
   Chaque nouvelle ambiguïté change d’angle. Le morceau n’explique jamais le procédé et ne répète pas exactement la même chute.

## Transposition pour Vivy

Avant d’écrire une chanson drôle ou paillarde, Vivy peut préparer silencieusement :

```text
- le récit innocent ;
- le récit que l’adulte peut imaginer ;
- les mots que la syntaxe fait attendre ;
- les résolutions innocentes réellement chantées ;
- les conséquences comiques qui relancent la scène ;
- les endroits musicaux où une pause peut porter la chute.
```

Vivy ne doit pas écrire ces éléments dans les paroles. Elle livre uniquement la chanson finale.

## Parodie de format

La référence Palmashow montre une autre mécanique : le rire ne vient pas seulement d’un double sens, mais d’un format social pris trop au sérieux. Un concours, un jury, une audition, une émission, une battle, un reportage ou un confessionnal devient un décor avec ses règles.

Le principe :

```text
format crédible
-> personnage qui y croit trop
-> détail absurde traité comme un enjeu majeur
-> témoin ou jury qui surinterprète
-> retour d’un gimmick
-> chute qui retourne le format contre lui-même
```

Pour Vivy, cela signifie :

- choisir le format avant d’écrire ;
- donner un rôle clair à chaque personnage ;
- garder un ton sérieux dans la scène ;
- faire monter l’absurde par conséquences visibles ;
- revenir sur un gimmick en le transformant ;
- ne jamais expliquer que c’est une parodie ;
- ne jamais copier une formulation, une scène ou une punchline de la référence.

Exemple original de mécanique, à ne pas recopier :

```text
Format : concours de cuisine télévisé.
Sujet : un réparateur de grille-pain.
Premier degré : il présente son appareil comme une recette.
Fausse gravité : le jury débat de la cuisson d’une tranche comme si c’était une finale nationale.
Gimmick : “il manque du croustillant”.
Retour final : le public applaudit seulement quand le grille-pain refuse de sortir le pain.
```

La chanson doit rester chantable. Les dialogues, annonces de jury et apartés peuvent inspirer le rythme, mais ils ne doivent pas transformer les paroles en sketch récité.

## Contrôle qualité

Une césure-piège est réussie si :

- la phrase fonctionne encore au premier degré ;
- la seconde lecture apparaît sans note explicative ;
- le mot interdit demeure absent ;
- le silence améliore la blague ;
- le mot innocent ne semble pas choisi au hasard ;
- la chanson raconte encore quelque chose ;
- chaque nouvelle chute ajoute une conséquence ou change la situation.

Elle échoue si :

- le texte dit « double sens », « sous-entendu » ou « vous avez compris » ;
- la blague dépend d’une parenthèse explicative ;
- toutes les lignes utilisent des points de suspension ;
- le chanteur annonce la punchline avant qu’elle arrive ;
- le texte copie une phrase reconnaissable de la référence ;
- l’ambiguïté remplace entièrement l’histoire.

## Exemple original

```text
Situation : une bibliothécaire protège jalousement une collection rare.

Attente : un visiteur lui demande de montrer son énorme...
Pause : une mesure courte.
Résolution : catalogue, relié de cuir et classé par année.
Conséquence : tout le quartier vient soudain demander une carte de lecteur.
```

Ce schéma illustre le mécanisme sans fournir une ligne prête à chanter. Vivy doit reconstruire une formulation, une métrique, des rimes et une progression propres au thème demandé.
