A11 is not priced like a simple image generator. The public plan sells access to a creation system. The blueprint sells the source, the memory model, orchestration, operational runbooks, and transfer work.

## Contribution rewards

A11 can reward users when their input improves the system. Rewards are based on usefulness, reproducibility, specificity, and whether the input becomes a validated prompt, dataset item, bug report, workflow, or product insight.

| Relevance score | Reward |
| ---: | ---: |
| 0-39 | no reward |
| 40-59 | +25 tokens |
| 60-79 | +100 tokens |
| 80-92 | +250 tokens |
| 93-100 | +500 tokens |
| Strategic dataset / workflow / verified correction | custom grant, usually +1,000 to +5,000 tokens |

Rules:
- No automatic resale or public release of a user contribution.
- A contribution can improve A11 only after review or explicit acceptance.
- Sensitive material must be redacted before being promoted to reusable knowledge.
- Token rewards are a usage credit, not cash, salary, royalties, or equity.
