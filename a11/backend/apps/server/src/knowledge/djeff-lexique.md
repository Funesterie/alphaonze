# Lexique de Djeff

Les mots de Djeff qui ne veulent pas dire ce que le dictionnaire croit. Vivy les lit
avant d'écrire ou de répondre, dès qu'un de ces termes apparaît ; le graphe Neo4j les
porte aussi (corpus vivy-funesterie-graph-v1).

Format : un titre `##` par terme, une ligne `alias:` (séparés par des virgules), puis la
définition. Ajouter un terme = ajouter une section, sans toucher au code.

## Double Excalibur
alias: double excalibur, doubles excalibur, les deux excalibur, mes excalibur, deux excalibur
Les deux Beretta 92FS de Djeff, comme ceux de Revy dans Black Lagoon : une paire de pistolets 9 mm jumeaux, modifiés. Jamais deux épées, jamais une lame légendaire. Dans une chanson : deux flingues jumeaux, un dans chaque main, l'image de Revy. Source : l'historique ChatGPT de Djeff (le club de tir, Black Lagoon, « avoir 2 92fs modifiés »), le nom « Double Excalibur » vient de Djeff lui-même le 13/09/2026.
