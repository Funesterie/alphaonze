# Changelog

All notable changes to the A11 VS Code extension will be documented here.

## [1.0.1] - 2026-05-22

### Changed

- Reworked the npm README for Kiro and VS Code-compatible editor usage.
- Documented `@nossen/*` as the maintained module namespace.
- Added visible support and donation information for the Funesterie/NOSSEN project.
- Updated public package metadata to avoid the retired personal funding path.

## [0.1.0] - 2025-01-01

### Added

- Initial release of A11 AI Coding Agent
- Chat sidebar with streaming responses
- Commands: explain, fix, refactor, generate, test, review, commit, docs, optimize, security
- Inline chat (Ctrl+I)
- Google OAuth authentication
- Trial mode: 50 free requests
- Status bar indicator
- Context menu integration
- Keyboard shortcuts
- Dark/light theme support
- Markdown rendering with syntax highlighting
- Code block copy button
- Conversation history
- Model selector
