# Changelog

All notable changes to the A11 VS Code extension will be documented here.

## [0.1.0] - 2025-01-01

### Added

- Initial release of A11 AI Coding Agent
- Chat sidebar with streaming responses
- Commands: explain, fix, refactor, generate, test, review, commit, docs, optimize, security
- Inline chat (Ctrl+I)
- Google OAuth authentication
- Trial mode: 50 free requests
- Status bar indicator
- Context menu integration
- Keyboard shortcuts
- Dark/light theme support
- Markdown rendering with syntax highlighting
- Code block copy button
- Conversation history
- Model selector
