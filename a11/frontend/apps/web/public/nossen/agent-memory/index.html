Where it overlaps with current graph-agent research.

The Neo4j public discussion around agent memory, semantic layers, GraphRAG and production agents matches a problem space NOSSEN has been exploring from the operational side.

Memory

Graph-backed context

Short-term dialogue, long-term entities, event traces and semantic links are routed through a Neo4j/Aura-aware memory layer.

Operations

MCP and agent bus

Agents, jobs, discussions and tool calls are coordinated through MCP surfaces instead of one-off manual relay.

Retrieval

Metadata-first source index

Source discovery uses hashes, labels and summaries before raw content, so sensitive corpora can remain governed.

Security

Operator-safe verification

Secrets are checked by use, scope and health, not by printing them into logs or chat transcripts.

Packaging

Public modules, private adapters

Reusable logic moves into installable `@nossen/*` packages while environment-specific adapters stay private.

Governance

Audit before autonomy

Agent actions are routed through explicit policies, diagnostics, rollback notes and human-visible checkpoints.
